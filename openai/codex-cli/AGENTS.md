# Suno Maestro (Codex CLI)
Este repositório contém o método Suno Maestro em `skill-core/`. Em QUALQUER pedido de criação musical (música, jingle, letra para Suno, álbum, trilha): 1) leia `skill-core/SKILL.md`; 2) leia os perfis da mescla escolhida em `skill-core/profiles/` (default: pincel-emocional) e `skill-core/blends.md`; 3) consulte `skill-core/references/` conforme a tarefa (metatags, multilíngue, styles, v5.5); 4) entregue Style + Exclude + Letra com tags + configurações. Constantes: Custom Mode; Style ≤1000 chars com idioma declarado; Weirdness 30-45%; Style Influence 70-85%; mín. 3 gerações antes de alterar prompt; refrão curto com nome/marca repetido; espelho honesto antes de compor.
