# ChatGPT — Custom GPT (ou Projeto)
1. chatgpt.com → Explorar GPTs → **Criar** (ou crie um **Projeto**).
2. Cole `INSTRUCTIONS.md` no campo Instructions (3,7k chars; limite 8k).
3. Em Knowledge, envie os 8 arquivos de `knowledge-files/`.
4. Capabilities: ative Web Browsing (para o passo de pesquisa). Salve.
Observação: aqui a skill vira método+conhecimento; subagentes e comandos são exclusivos do Claude Code.
